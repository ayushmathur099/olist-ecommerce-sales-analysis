# olist-ecommerce-sales-analysis
End-to-end Business Analytics project using SQL, Python and Tableau on the Olist Brazilian E-Commerce dataset.

---

## About the Project
This project was completed as part of my Business Analytics portfolio to practice working with real-world business data. I used the Olist Brazilian E-Commerce dataset to analyze sales performance, customer behavior, payment methods and delivery trends. The goal was to take raw data from multiple tables, clean and prepare it for analysis, explore meaningful business insights, and build an interactive Tableau dashboard that summarizes the results.

---

---

## Project Workflow

### Data Preparation
- Explored the database structure
- Combined multiple tables using SQL joins
- Cleaned missing values and duplicate records
- Standardized column names and data types

### Feature Engineering
Created additional columns such as:
- Order Year
- Month
- Quarter
- Weekday
- Delivery Days

These features made it easier to analyze trends over time.

### Exploratory Data Analysis

I explored questions such as:
- How does revenue change over time?
- Which product categories generate the most revenue?
- Which payment methods do customers prefer?
- How long does delivery usually take?
- How satisfied are customers based on review scores?

## Key Findings

Some interesting insights from the analysis include:

- Credit cards are the most frequently used payment method.
- A small number of product categories contribute a large share of total revenue.
- Customer reviews are generally positive, with an average rating above 4.
- Average delivery time is around 12 days, suggesting opportunities to improve logistics.
